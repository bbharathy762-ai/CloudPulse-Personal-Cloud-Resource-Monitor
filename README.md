# CloudPulse – Personal Cloud Resource Monitor

CloudPulse is a simple cloud computing sample project that displays a dashboard of simulated cloud resource metrics.

live Website:
## Features

- CPU usage monitor
- Memory usage monitor
- Storage usage monitor
- Active cloud instance count
- Resource activity chart
- Cloud service health list
- Responsive design
- Refresh button with simulated live data

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click **Refresh Data** to generate new sample metrics.

## Deployment

This project is a static website, so it can be deployed using:

- GitHub Pages
- Netlify
- Vercel
- Any static web hosting service

## Cloud Computing Concept

The project demonstrates the idea of **cloud resource monitoring**. In a real cloud environment, the values shown on this dashboard could be collected from monitoring APIs such as AWS CloudWatch, Azure Monitor, or Google Cloud Monitoring. This student version uses simulated data so that it can run without paid cloud services or API credentials.
